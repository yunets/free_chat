## 简介

Free Chat 是一款简洁的 AI 大模型对话前端应用，无需部署后端服务，直接在浏览器中配置 API 即可与 AI 进行对话。

### 主要特点

- **零部署**: 纯前端应用，无需服务器
- **多 API 支持**: 可配置多个 API 端点
- **流式输出**: 实时显示 AI 回复
- **Markdown 支持**: 代码高亮、格式丰富
- **本地存储**: 数据保存在浏览器中

## 快速开始

### 1. 安装

```bash
git clone https://gitee.com/liuysh/free_chat.git
cd free_chat
npm install
```

### 2. 启动

```bash
npm run dev
```

浏览器访问 http://localhost:8888

### 3. 配置 API

1. 点击侧边栏底部的 **"⚙️ 设置"** 按钮
2. 在 API 配置区域填写：
   - **配置名称**: 给配置起个名字（可选）
   - **API URL**: API 端点地址
   - **API Key**: 你的 API 密钥
   - **模型**: 使用的模型名称
3. 点击 **"⭐ 设为默认"** 将该配置设为默认

### 4. 开始对话

1. 点击 **"+ 新对话"** 创建新会话
2. 在输入框中输入问题
3. 按 Enter 发送消息

## API 配置

### 添加新配置

1. 点击 **"⚙️ 设置"**
2. 点击 **"+ 添加配置"**
3. 填写配置信息

### 配置字段说明

| 字段 | 说明 | 示例 |
|------|------|------|
| 配置名称 | 标识配置的名字 | OpenAI、Claude |
| API URL | API 端点地址 | `https://api.openai.com/v1/chat/completions` |
| API Key | 访问密钥 | `sk-xxxxxxxx` |
| 模型 | 使用的模型 | `gpt-3.5-turbo`、`gpt-4` |

### 常用 API 配置

#### OpenAI

```
API URL: https://api.openai.com/v1/chat/completions
模型: gpt-3.5-turbo 或 gpt-4
```

#### Azure OpenAI

```
API URL: https://{your-resource}.openai.azure.com/openai/deployments/{deployment-name}/chat/completions?api-version=2024-02-01
模型: 你的部署名称
```

#### Claude (通过 OpenAI 兼容接口)

```
API URL: https://api.anthropic.com/v1/messages
模型: claude-3-sonnet-20240229
```

### 管理配置

- **设为默认**: 点击配置旁边的 "☆ 设为默认" 按钮
- **克隆配置**: 点击 "📋 克隆" 复制当前配置
- **删除配置**: 点击 "×" 删除配置（至少保留一个）

## 对话功能

### 发送消息

- 在输入框输入内容
- 按 **Enter** 发送
- 按 **Shift+Enter** 换行

### 新建会话

- 点击侧边栏的 **"+ 新对话"** 按钮
- 或在欢迎页面点击 **"开始对话"**

### 切换会话

- 点击侧边栏中的历史会话
- 会自动加载该会话的聊天记录

### 删除会话

- 鼠标悬停在会话上
- 点击出现的 **"×"** 按钮

### 中断响应

- 如果 AI 回复时间过长，可以直接发送新消息中断

---

## 复制功能

### 复制按钮

- 鼠标悬停在 AI 回复上
- 右侧显示两个复制按钮：
  - **📄**: 复制纯文本（去除 Markdown 格式）
  - **📋**: 复制 Markdown 源码

### 复制成功

- 复制成功后，按钮显示 **"✓"**
- 2 秒后恢复原图标

## 数据存储

### 存储内容

以下数据保存在浏览器 localStorage：

- API 配置（URL、Key、模型）
- 默认配置 ID
- 所有会话历史
- 当前选中的会话

### 数据安全

- 数据仅保存在本地浏览器
- 不会上传到任何服务器
- 清除浏览器数据会导致丢失

### 导出/备份

如需备份，可以手动复制 localStorage 中的数据：

1. 打开浏览器开发者工具 (F12)
2. Application → Local Storage
3. 查看 `free_chat_*` 开头的键值

## 常见问题

### Q: 为什么发不了消息？

A: 请检查：
1. 是否已配置 API（设置中填写 URL、Key、模型）
2. API Key 是否正确
3. 网络是否正常

### Q: 提示模型名称为空？

A: 需要在设置中填写 "模型" 字段，如 `gpt-3.5-turbo`

### Q: 复制按钮不显示？

A: 鼠标悬停在 AI 回复上才会显示复制按钮

### Q: 如何切换不同的 API？

A: 
1. 点击 "⚙️ 设置"
2. 在配置列表中找到目标配置
3. 点击 "☆ 设为默认"

### Q: 数据保存在哪里？

A: 数据保存在浏览器 localStorage 中，清除浏览器数据会丢失
